# Security Policy

## Supported versions

This project is actively maintained in the current repository state. Security fixes are prioritized for the latest code on the default branch.

## Reporting a vulnerability

Please do not open a public issue for security vulnerabilities or exploit details.

Report them privately through one of the following channels:

- GitHub Security Advisories for this repository: https://github.com/Ifaz2611/chess-X/security/advisories/new
- A private maintainer contact available through the repository owner profile or project admin configuration

When reporting, include:

- a clear description of the issue
- affected file or module name
- reproduction steps or proof of concept
- impact assessment
- any suggested mitigation

We ask that you allow a reasonable amount of time for a fix to be prepared before public disclosure.

## Scope

Examples of issues to report:

- unsafe file handling or path traversal
- command execution or script injection issues
- local privilege misuse or dangerous execution paths
- dependency vulnerabilities in the project or build tooling
- unsafe handling of browser automation or external process integration

Examples that are not considered security issues:

- feature requests or normal bug reports
- questions about project usage
- concerns about fair-play misuse or policy violations by users of the bot

## Ethical disclosure

We appreciate responsible disclosure. Please do not intentionally damage systems, expose personal data, or publicly post exploit details before the issue has been addressed.

## Response expectations

- Acknowledge receipt of the report as soon as practical
- Triage the issue for severity and impact
- Coordinate on a fix and disclosure plan when appropriate

This project uses browser automation and external site interaction, so any security issue involving local execution, file access, or browser automation should be treated seriously. We will do our best to address valid reports quickly and transparently.

## Fair play and safe use

This tool is intended for educational, local, and private-board use only. It should not be used against human opponents in online rated games. Any security issue that enables cheating or abuse against third-party services remains a high-priority concern and will be handled privately.
